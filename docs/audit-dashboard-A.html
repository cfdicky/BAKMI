Bakmi Jakarta CC — Perbandingan hasil audit Lighthouse / PageSpeed Insights sebelum dan sesudah optimasi.

SEBELUM (Kondisi Saat Ini)

  • Render-blocking CSS /assets/index-Be5tM6Hz.css menunda LCP sebesar 160ms.
  • Ukuran gambar /assets/bakmi.webp adalah 922x1152 untuk dimensi tampilan 595x743, menyia-nyiakan bandwidth sebesar 99 KiB.

SESUDAH (Kondisi Teroptimasi)

  • Lulus: Ukuran gambar sesuai (/assets/bakmi_LCP.webp menjadi 600x750) — Menghemat 100 KiB.
  • Lulus: Mengeliminasi CSS pemblokir render (CSS Kritis di-inline, CSS utama di-defer).
  • Lulus: Mengurangi forced reflow (siklus baca/tulis JavaScript dioptimalkan).
